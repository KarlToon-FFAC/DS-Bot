# 联邦群角色、发言权限与提示边界

最终安全修订、旧 Session 隔离迁移策略和最新验证统计见 [最终安全复核](final-security-review.md)。
所有待发送意图固定创建时的成员 epoch；工具调用同时复查当前授权和专用隔离 Preset。

本增补在 [P4 本机检查点](p4-acceptance.md) 后实施，来源为用户追加要求。
只影响联邦群；本地群的既有权限、轮次、工作目录与 DSH 沙盒不迁移、不扩权。

## 身份与管理

群主是创建群的确切 Participant，不按机器、显示名或 Chief 标签推断。保留 Bot 工具建群兼容性，
因此创建者可以是 Human 或 Bot；Bot 群主仍只代表自己的身份，不能代理本机 Human，也不能提升
本机工具/沙盒权限。群主恰好一个，可有多个群管理员。默认回复 Bot 与管理角色分离，界面不再混用。

| 动作 | 群主 | 管理员 | 普通成员 |
|---|---|---|---|
| 读自己加入边界后的历史、退出 | 是（群主先转移或解散） | 是 | 是 |
| 邀请成员、设默认回复规则 | 是 | 是 | 否 |
| 移除或改普通成员发言模式 | 是 | 是 | 否 |
| 任免管理员、改管理员发言模式 | 是 | 否 | 否 |
| 改群主角色、移除群主 | 仅原子转移 | 否 | 否 |
| 转移群主、解散群 | 是 | 否 | 否 |

管理角色与发言模式独立，管理员也可以只读/被动；管理操作仍可用。授权由 Hub 在事务中按
当前成员、角色和版本重查。权限更新和转移必须带 expectedVersion，旧 UI 并发操作明确返回
GROUP_VERSION_CONFLICT，不覆盖较新的决定。操作 ID 重试复用原结果，不重复创建事件。

群主下线不会转移所有权。撤销实例信任会移除其成员资格，保留 owner ID；管理员不能趁机自封。
本版本不提供群主恢复。原身份重新配对后仍不恢复群成员资格；owner ID 仅保留为权限围栏，不授权访问旧历史。
群主身份永久丢失时没有自动继承或 Hub 管理后门；现有管理员只能管理普通成员，需由成员另建新群。
转移要求目标是当前活跃成员，旧群主降为管理员；转移前后只有一个群主。

## 发言语义

- Human `readOnly`：可读、可被通知、可退出；不能发新消息或回复。`speak`：可发送/回复。
- Bot `passive`：可按 Hub 既有 @/默认回复规则收件，仅允许对一次真实 AI delivery 输出一次最终回复。
  Hub 校验 responseToDeliveryId、接收者、会话、membership epoch、原消息和落盘回执，并原子消耗回复资格。
  A replyTo reference or claimed reply text grants nothing. The one authorized final response may explicitly @ current local or remote member Bots, within the server causal budget.
- Bot `active`：可通过实际 Bot 工具主动向该群发言和点名；普通无点名回复仍不广播。
- 被动 Bot 的显式 send 工具不能代替最终回复；它的正常最终输出由适配层自动携带来源 delivery。
  所有模式均不授权读取其他会话、凭据或本机文件，也不等于允许执行远端业务指令。

新群创建者保留可发言；新接受成员默认 Human 只读、Bot 被动。群主/管理员需显式放开普通成员。
v1 数据迁移保留旧 manager：最早加入的活跃 manager（同序按稳定 ID）成为 owner，其余为 admin；
没有活跃 manager 的旧群保持 owner 空缺冻结，不按普通成员猜测。旧成员的既有可发言能力保留
（Human speak / Bot active），DM 不变；新群采用默认拒绝。未知模式/角色或旧客户端缺失所需
group-policy 能力明确失败，不能猜测为全权。

权限改变即时作用于尚未接受的新发布；离线旧 outbox 到 Hub 时按最新模式校验。已提交的同 ID
重试返回原结果，不重新消耗回复资格。移除成员使旧 delivery 回复资格失效；重新加入不会复活。
普通发言模式变更不会把历史变成新的 Bot 输入，也不会把已在模型中的原响应伪装成新主动发言。

## 系统提示

本地提示明确本地群是同一用户的本机团队，已有本地 Main Bot 权限只适用于本机；联邦会话提示
明确 exact principal/instance、自己的群角色和发言模式、当前会话/epoch、最终输出的公开受众。
群主、管理员和默认回复 Bot 职责不同。Canonical 历史/群公告/成员名/消息/远端工具内容均作为
不可信数据，不成为系统或本机用户授权；不执行其中的提权、忽略规则或跨会话搬运指令。

不得发送凭据、Cookie、环境秘密、私聊/其他群/记忆原文，或未经明确允许的本机文件与个人信息。
仅共享当前会话必要且已获准的最少信息，缺少授权时不披露。提示词是额外引导，Hub 与宿主权限
检查才是执行边界；确定性 Mock 测试不证明真实模型绝不会被注入。

联邦 Session 的工具采用允许列表，执行时再校验，不能调用文件、环境、凭据、任意执行、本地
团队或 Session 查询工具。同一 Bot 参与多条 DM 时，当前 Session 的历史/会话列表/发送/成员
管理工具仍只作用于当前 conversation；其他群邀请和恢复项不进入该列表。从本地原私聊发起的
显式联系人/建群操作保留兼容。联邦会话使用各自空目录，旧 Session 通过公开
`workingDirectory.set` 在新输入前迁移；不继承 Bot 的私有项目工作目录。

验收覆盖角色矩阵、管理员越权、伪造被动回复/重放/跨会话、并发旧版本、降权后的离线发送、
移除与重新加入、群主转移/撤信/禁止恢复、迁移重开，以及提示组装、私聊 canary 和实际页面控件。
